# 大仓鼠题库

`docs/` 是可通过 GitHub Pages 发布的总入口。科目页可以列出多套题库，并保留来源文件名。已上线的药理学 A 入口打开原刷题系统。

注册、邮箱验证码、闲鱼订单、旧 ID 迁移和找回密码使用现有题库模块。同一账号可登录两站。新站的练习记录按账号和题库保存在当前浏览器。

正式题库使用 Supabase 中的私有表。新增接口仅向已验证邮箱、未停用的学员返回已发布的题库。公开仓库只提交题库目录和源代码。目录中的未发布题库会显示整理或复核状态。

`tools/build_catalog.py` 接收豆包的逐项解析 JSON，并按校验后的题目哈希筛出题目。脚本分别生成公开目录和私有导入数据。确认题库已发布后，使用 `--publish 题库ID` 生成开放入口。题干、答案、逐项解析和原始来源文件随私有数据管理。
